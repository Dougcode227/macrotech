
# 🌐 Macrotech — Site

Site institucional da **Macrotech**, uma empresa especializada em eletrônica, assistência técnica de celulares e venda de acessórios, localizada em Porto Alegre/RS.

## 📄 Descrição

O site oferece informações sobre os serviços prestados, produtos à venda e formas de contato da empresa. Desenvolvido com HTML e CSS puro, tem como objetivo fornecer uma experiência clara e objetiva para o cliente final.

## 📁 Estrutura dos Arquivos

```
├── index.html        # Página inicial com apresentação da empresa, serviços e produtos
├── contato.html      # Página com informações de contato e mapa de localização
├── style.css         # Estilo visual e responsividade do site
├── images/           # Pasta com imagens (logotipo, ícones, fotos dos produtos)
```

## 🧰 Tecnologias Utilizadas

- HTML5
- CSS3 (com media queries para responsividade)
- Google Maps (embed via iframe)
- Links diretos para WhatsApp e email

## 📱 Responsividade

O layout foi projetado para ser totalmente responsivo, adaptando-se bem a telas de smartphones, tablets e desktops.

## 🧩 Funcionalidades

- Exibição dos principais serviços oferecidos (conserto de celulares, troca de tela, reparo de placas etc.)
- Galeria com produtos em destaque
- Botões de contato direto via WhatsApp e email
- Mapa interativo da localização da empresa
- Interface moderna com botões animados e seções bem definidas
